Sobre o aplicativo

O Forense Backup é um aplicativo de uso privado e restrito, utilizado para transferir, organizar e verificar arquivos de backup em uma conta Google Drive autorizada pelo próprio usuário.

Finalidade

O aplicativo pode utilizar a API do Google Drive para:

  • criar pastas destinadas ao armazenamento de arquivos;
  • enviar arquivos para o Google Drive;
  • consultar metadados necessários para confirmar a conclusão de transferências;
  • organizar arquivos criados ou enviados pelo próprio fluxo de backup.
Uso restrito. O Forense Backup não é oferecido como serviço público, não possui cadastro aberto de usuários e não comercializa acesso a dados ou funcionalidades.

Dados do Google

O acesso ao Google Drive ocorre somente após autorização OAuth do usuário. O aplicativo não vende dados, não utiliza dados para publicidade e não cria perfis comerciais de usuários.
